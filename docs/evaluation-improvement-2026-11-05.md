- 기존 검색 정상 1회차는 선행 검색을 생략하여 제보된 전체 절차를 수행하지 않았다.
- 기존 필터 정상 3회차와 추가 알림 닫기 정상 사례는 작업 전 상태 문구를 완료 조건으로 사용했다.
- 기존 잘림 정상 3회차는 정상 판정 대신 추가 정보를 요청했다.
- 추가 버튼 활성화 버그는 비활성 상태를 관찰해야 하는 버튼을 클릭하려 하여 실행이 막혔다.
- 추가 목록 중복 버그는 재작성 후에도 마지막 결과 강제 단계가 남아 실행 전에 거절됐다.

## 제한과 다음 단계

- 기능 사례는 제보에 지정된 입력과 조작 일치를 요구한다. 동일 증상을 다른 입력으로 관찰한 경우도 미통과할 수 있다.
- 질문은 분기와 질문 존재만 자동 채점한다. 질문의 유용성·원인 가설·해결 방안의 정확성은 별도 사람 평가가 필요하다.
- 정상 구현에서 과거 버그 제보를 검증하는 사례다. 정상 스크린샷 분류 정확도와 구분한다.
- 이번 변경은 QA 재현·검증 개선이며 고객사 코드를 자동 수정하지 않는다.
- 여러 개선을 함께 적용했으므로 개별 변경의 기여도나 모델 응답 변동을 분리해 측정한 실험은 아니다.
- 두 번째 모델은 근거와 반례를 검토하는 역할로 설계하되, 동일 예산의 단일 모델 자기 검토와 비교한 뒤 도입한다. [비판 모델 제안](critic-review-proposal.md).

# SDK 최근 조작 기록 (0.8.0)

`QARequest.reporter_activity`는 선택 문자열이며 최대 8192자입니다. 기존 요청은 그대로
동작합니다. 백엔드는 별도 동의를 받은 최근 120초·20개 기록을 범위 검사·정제한 후
경로, 클릭 선택자·이름, 클릭 뒤 안내 문구를 시간순 텍스트로 전달합니다. 입력값과
쿠키·인증 정보·요청 본문은 전달하지 않습니다. 원본 JSON은 백엔드 신고 컨텍스트에 둡니다.

이 필드는 intake, 계획, critic에 전달되며 원문 인용의 근거가 됩니다. 모델이 이미 기록된
클릭 순서·완료 문구를 다시 질문하지 않도록 안내합니다. 클릭 뒤 경로 변경은 결과일 수
있으므로 추가 사용자 이동으로 중복 실행하지 않습니다. 기록의 첫 준비 경로가 신고
주소와 다르면 신고 주소 방문 뒤 그 준비 경로를 보존합니다.

기록은 신뢰하지 않는 입력이며 실행 권한이나 재현 증거가 아닙니다. 범위·쓰기 승인·계정
초기화·두 번 관찰한 결과에 따른 판정은 유지합니다. 누락된 입력값이나 서버 상태는
추정하지 않습니다. 전체 새로고침 전 기록과 2분보다 오래된 준비 상태는 없을 수 있습니다.
재검증·추가 답변 실행에는 저장된 기록을 유지하고 구버전 request.json도 읽습니다.

`test_activity_flow.py`는 실제 Chromium과 모의 모델로 짧은 신고→기록 기반 계획→critic→
두 번 재현→재검증을 확인합니다. 이 테스트의 성공은 실제 AI의 질문 감소율이나 성공률을
의미하지 않습니다. 배포 뒤 같은 신고 사례를 기록 유무로 비교해 별도로 측정해야 합니다.
